# Louise Nicole N. Madriaga — Portfolio

A responsive personal portfolio built for Web Development 1. Content (Skills, Projects, Education, Certifications, Life Beyond Coding) lives in `data.json` and is rendered onto the page by `js/main.js` — edit the JSON, not the HTML.

**Live site:** https://louiseeo.github.io/Portfolio/

## Built With

- HTML5 & CSS3 (Flexbox, Grid, media queries)
- Vanilla JavaScript (`fetch()`, DOM APIs)
- Google Fonts (Inter, Space Grotesk, JetBrains Mono)

## Project Structure

```
Portfolio/
├── index.html
├── data.json      # all content
├── css/styles.css
├── js/main.js     # loads data.json and renders it
└── assets/        # photos & images
```

## Running Locally

Just visit the live site: https://louiseeo.github.io/Portfolio/

## Editing Content

Add or edit entries in `data.json` — new cards appear automatically, no HTML changes needed.
